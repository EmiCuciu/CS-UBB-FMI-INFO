Ce este CMMP?

Problema generală

Minimizarea erorii în normă L²

Dat f ∈ L²_w[a,b] și Φ ≤ L²_w[a,b] subspațiu de dimensiune n+1, găsim φ* ∈ Φ cu:

‖φ* − f‖₂ ≤ ‖φ − f‖₂, ∀φ ∈ Φ

φ* = a₀φ₀ + a₁φ₁ + … + aₙφₙ unde {φₖ} este o bază a lui Φ.

6a — Caz discret

Produsul scalar discret

(g, h) = Σₖ wₖ · g(xₖ) · h(xₖ) Minimizăm: Σₖ wₖ(f(xₖ) − φ*(xₖ))²

N date (xₖ, fₖ), N > n+1 → sistem supradeterminat.

6b — Caz continuu

Produsul scalar integral

(g, h) = ∫_a^b w(x)·g(x)·h(x)dx Minimizăm: ∫w(x)(f(x)-φ*(x))²dx

Pondere w(x) ≥ 0 dată.

6a — Aproximarea Discretă (baza 1, x, ..., xⁿ)

Matricea de design A (Vandermonde)

Coloanele = valorile bazei în noduri

A ∈ ℝ^{N×(n+1)}, A_{ij} = φ_{j-1}(xᵢ) = xᵢ^{j-1} ⎡ 1 x₁ x₁² … x₁ⁿ ⎤ ⎡ f₁ ⎤ ⎢ 1 x₂ x₂² … x₂ⁿ ⎥ · ⎢ c ⎥ ≈ ⎢ f₂ ⎥ ⎢ … … … … … ⎥ ⎢ … ⎥ ⎢ … ⎥ ⎣ 1 xN xN² … xNⁿ ⎦ ⎣ cₙ ⎦ ⎣ fN ⎦

Dacă N > n+1 → sistem supradeterminat → rezolvat în sensul CMMP.

Coeficienții — soluția CMMP c = A \ f ← MATLAB rezolvă intern cu QR decomposition

Echivalent cu ecuațiile normale AᵀAc = Aᵀf, dar numeric mai stabil prin QR.

Ecuațiile Normale

Derivarea ecuațiilor normale

Minimizăm E(c) = ‖Ac − f‖² → ∂E/∂cₖ = 0

AᵀA · c = Aᵀf ← Ecuațiile normale

Matricea AᵀA este simetrică pozitiv definită (dacă A are rang maxim).

Elementele: (AᵀA)_{ij} = Σₖ xₖ^{i+j-2} = (φᵢ₋₁, φⱼ₋₁) (Aᵀf)_i = Σₖ xₖ^{i-1}·fₖ = (f, φᵢ₋₁)

AᵀA poate fi prost condiționată pentru n mare (Vandermonde e notorie!). MATLAB's `\` folosește QR — mai stabil.

6b — Aproximarea Continuă

Ecuațiile normale (continuu)

Dacă baza {φₖ} e generică:

Σⱼ aⱼ(φⱼ, φₖ) = (f, φₖ), k = 0, …, n Gram · a = b, Gram_{kj} = (φₖ, φⱼ) = ∫w·φₖ·φⱼdx bₖ = (f, φₖ) = ∫w·f·φₖdx
Dacă baza e ORTOGONALĂ → simplificare

(φⱼ, φₖ) = 0 pentru j≠k → Gram e diagonală!

aₖ = (f, φₖ) / (φₖ, φₖ) ← formule explicite!

Nu trebuie rezolvat niciun sistem! Acesta este marele avantaj al bazelor ortogonale.

Aproximarea Continuă cu Polinoame Chebyshev

Produsul scalar Chebyshev

Pondere w(t) = 1/√(1-t²) pe [-1,1]

(g, h) = ∫₋₁¹ g(t)h(t) / √(1-t²) dt Ortogonalitate: (Tₖ, Tⱼ) = { 0, k≠j { π, k=j=0 { π/2, k=j>0
Coeficienții Chebyshev φ*(x) = a₀T₀(x) + a₁T₁(x) + … + aₙTₙ(x) a₀ = (1/π) ∫₋₁¹ f(t)/√(1-t²) dt aₖ = (2/π) ∫₋₁¹ f(t)Tₖ(t)/√(1-t²) dt, k≥1

Schimbare variabilă t=cos(θ): integrala devine ∫₀^π f(cos θ)cos(kθ)dθ — transformată cosinus!

Implementare discreta (N+1 puncte Chebyshev) ξₖ = cos((2k-1)π/(2N+2)), k=1,…,N+1 (radacinile T_{N+1}) a₀ ≈ (1/(N+1)) Σₖ f(ξₖ) aⱼ ≈ (2/(N+1)) Σₖ f(ξₖ)·Tⱼ(ξₖ), j≥1 Tₖ(x) calculat din recurenta: T₀=1, T₁=x, Tₙ₊₁=2x·Tₙ-Tₙ₋₁

Converge spectral pentru funcții analitice: ‖f-φ*‖ = O(C^{-n}), C>1.

Calitatea Fitului — R² și Reziduu

Norma reziduului ‖r‖ = ‖Ac - f‖₂ = √(Σᵢ(Acᵢ-fᵢ)²) Mic = fit bun Compara modele: mai mic → mai precis
Coeficientul R² SS_res = ‖Ac - f‖² (eroare model) SS_tot = ‖f - f̄‖² (varianță totală) R² = 1 - SS_res/SS_tot ∈ [0, 1] R²→1: model excelent R²→0: model slab
Compararea modelelor

Model cu mai mulți parametri → R² mai mare, dar poate fi overfitting. Criteriu mai bun: R² ajustat sau criteriul AIC/BIC, care penalizează complexitatea modelului.

R²_adj = 1 - (1-R²)(N-1)/(N-p-1) N = nr. date, p = nr. parametri

Problema 1 — Aproximare Discretă, w=1, baza 1,x,...,xⁿ

Cerință

Date (xₖ, fₖ), k=1,…,N. Găsește p*(x) = Σⱼ cⱼxʲ cu ‖Ac-f‖₂ minimă.

Rezolvare pe foaie — exemplu mic

Date: N=4 puncte, grad n=1 (dreaptă CMMP) x = [0, 1, 2, 3]', f = [1, 2, 2, 4]'
Pasul 1 — Matricea de design A A = [1 0] Coloana 1: φ₀(x) = 1 [1 1] Coloana 2: φ₁(x) = x [1 2] [1 3]
Pasul 2 — Ecuațiile normale AᵀAc = Aᵀf AᵀA = [4 6 ] Aᵀf = [9 ] [6 14 ] [17] Sistem: 4c₀ + 6c₁ = 9 6c₀ + 14c₁ = 17 Din prima: c₀ = (9 - 6c₁)/4 Substituind: 6(9-6c₁)/4 + 14c₁ = 17 → 13.5 - 9c₁ + 14c₁ = 17 → 5c₁ = 3.5 → c₁ = 0.7 c₀ = (9 - 6·0.7)/4 = (9-4.2)/4 = 4.8/4 = 1.2
Pasul 3 — Rezultat p*(x) = 1.2 + 0.7x Verificare reziduu: p*(0)=1.2, p*(1)=1.9, p*(2)=2.6, p*(3)=3.3 r = [1-1.2, 2-1.9, 2-2.6, 4-3.3] = [-0.2, 0.1, -0.6, 0.7] ‖r‖ = √(0.04+0.01+0.36+0.49) = √0.9 ≈ 0.949

Problema 2 — Asteroidul

Cerință

10 observații (xₖ, yₖ). Fit elipsoidal: x²=ay²+bxy+cx+dy+e. Fit parabolic: x²=ay+e.

Rezolvare pe foaie — logică

Model elipsoidal — setup matrice
  1. Necunoscute: a, b, c, d, e → 5 parametri
  2. Ecuația x² = ay²+bxy+cx+dy+e → pentru fiecare observație k: xₖ² = ayₖ²+bxₖyₖ+cxₖ+dyₖ+e
  3. Matricea design: A ∈ ℝ^{10×5} cu coloanele [y², xy, x, y, 1]
  4. Membrul drept: b = [x₁², x₂², ..., x₁₀²]ᵀ
  5. Soluție CMMP: [a,b,c,d,e]ᵀ = A\b
Model parabolic — setup (mai simplu)
  1. x² = ay + e → 2 parametri: a, e
  2. A ∈ ℝ^{10×2} cu coloanele [y, 1]
  3. Același b = x²
Comparare modele Rezultate numerice: Elipsoidal: ‖reziduu‖ ≈ 0.0033, R² ≈ 0.9997 Parabolic: ‖reziduu‖ ≈ 0.0218, R² ≈ 0.9768 Concluzie: R²_elipsoidal >> R²_parabolic → Modelul elipsoidal descrie mult mai bine orbita. → Orbita este elipsă (consistent cu prima lege a lui Kepler!) Elipsa are 5 grade de libertate, parabola 2 → mai mulți parametri dar R² mult mai bun → nu e overfitting, modelul e corect fizic.

Problema 4 — Populația SUA

Date

13 recensăminte (1900-2020). Fit polinomial gr.3 și exponențial.

Rezolvare pe foaie

Model polinomial grad 3
  1. Normalizare timp: t = (an - 1900)/10 → t ∈ [0, 12] evită probleme numerice
  2. Necunoscute: c₀, c₁, c₂, c₃ → y = c₀ + c₁t + c₂t² + c₃t³
  3. Matrice A ∈ ℝ^{13×4}: coloanele [1, t, t², t³]
  4. Soluție: c = A\pop
c_pol ≈ [74.7, 8.1, 0.7, -0.02] (ordine crescătoare) Predictii: 1975 (t=7.5): y ≈ 213 mln 2015 (t=11.5): y ≈ 320 mln
Model exponențial — liniarizare
  1. y = K·e^{λt} → log(y) = log(K) + λt
  2. Definim z = log(y), A = [1, t], necunoscute [log(K), λ]
  3. Sistem liniar: z = A·[log(K); λ] → soluție CMMP
  4. Recuperare: K = e^{c₁}, λ = c₂
K ≈ 80.0, λ ≈ 0.131 per deceniu → rata de crestere ≈ 1.31% per an Predictii: 1975 (t=7.5): y ≈ 216 mln 2015 (t=11.5): y ≈ 332 mln
Comparare modele Model polinomial: ‖reziduu‖ ≈ 3.5 mln (fit mai bun 1900-2010) Model exponential: ‖reziduu‖ ≈ 8.2 mln (mai slab la extremitati) Observatie: populatia SUA a incetinit cresterea dupa 1950 (efectul World War II, baby boom, etc.) — modelul exponential supraestimeaza in zona 1930-1950.
