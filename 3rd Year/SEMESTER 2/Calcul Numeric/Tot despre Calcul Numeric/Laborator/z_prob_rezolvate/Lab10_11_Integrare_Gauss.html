LAB 10 — Integrare Numerică

Formule Repetate (Prob 1)

Formula repetată a trapezului

O(h²), h = (b-a)/n

∫_a^b f(x)dx ≈ h/2 [f(a)+f(b) + 2Σ_{k=1}^{n-1} f(xₖ)] R₁(f) = −(b−a)³/(12n²) · f″(ξ) ← eroarea scade cu h²
Formula repetată a dreptunghiurilor (mijloc)

O(h²), mai precis decât trapezul cu același h

∫_a^b f(x)dx ≈ h Σ_{k=1}^n f((x_{k-1}+xₖ)/2) R₁(f) = +(b−a)³/(24n²) · f″(ξ) ← eroare opusă față de trapez!
Formula repetată a lui Simpson

O(h⁴) — mult mai precisă, n par!

∫_a^b f(x)dx ≈ h/6 [f(a)+f(b) + 2Σ f(x_{2k}) + 4Σ f(x_{2k-1})] R₂(f) = −(b−a)⁵/(2880m⁴) · f⁽⁴⁾(ξ) (n=2m)

Simpson = combinația ponderată (trapez + dreptunghi) care anulează termenul de eroare O(h²).

Erori prin Teorema lui Peano

Formula restului prin Peano

Rₙ(f) = ∫_a^b Kₙ(t) · f⁽ⁿ⁾(t) dt

Nucleul Peano: Kₙ(t) = 1/(n-1)! · Lₓ[(x-t)₊ⁿ⁻¹]

Dacă Kₙ(t) ≥ 0 → ∃ ξ: Rₙ(f) = f⁽ⁿ⁾(ξ)/n! · Lₓ(eₙ)

Cuadraturi Adaptive (Prob 3)

Idea de bază — Divide and Conquer

Rafinare locală unde funcția oscilează rapid

  1. Aplică formula pe [a,b]: Q₁
  2. Aplică formula pe 2 subintervale: Q₂
  3. Dacă |Q₂-Q₁| < tol → returnează Q₂
  4. Altfel → recursiv pe [a,c] și [c,b] cu tol/2

Toleranța se reduce cu 2 la fiecare nivel pentru că intervalul se înjumătățește.

Adaptive trapez Q1 = h/2*(f(a)+f(b)) Q2 = h/4*(f(a)+2f(c)+f(b)) if |Q2-Q1| < tol → Q2 else → recurse
Adaptive Simpson (simplu) S1 = h/6*(f(a)+4f(c)+f(b)) S2 = h/12*(f(a)+4f(d)+2f(c) +4f(e)+f(b)) if |S2-S1| < tol → S2 else → recurse

Metoda lui Romberg (Prob 4)

Trapeze + Extrapolare Richardson

Tabloul Romberg R_{k,j}

R_{1,1} = h₁/2*(f(a)+f(b)) R_{k,1} = ½*(R_{k-1,1} + h_{k-1}*Σ f(puncte_noi)) ← trapez injumatatit R_{k,j} = (4^{j-1}*R_{k,j-1} - R_{k-1,j-1}) / (4^{j-1}-1) ← extrapolare Criteriu oprire: |R_{k,k} - R_{k-1,k-1}| < ε

Coloana j corespunde la O(h^{2j}) — eroarea scade spectral!

Exemplu — ∫₀^π sin(x)dx = 2, ε=0.1 R₁,₁ = π/2*(0+0) = 0 R₂,₁ = ½*(0 + π*sin(π/2)) = 1.5708 R₂,₂ = 1.5708 + (1.5708-0)/3 = 2.0944 R₃,₁ = ½*(1.5708 + π/2*(sin(π/4)+sin(3π/4))) = 1.8961 R₃,₂ = 1.8961 + (1.8961-1.5708)/3 = 2.0045 R₃,₃ = 2.0045 + (2.0045-2.0944)/15 = 1.9985 |R₃,₃ - R₂,₂| = |1.9985-2.0944| = 0.096 < 0.1 ✓

adquad — Algoritmul 1 (Prob 5)

Simpson adaptiv CU extrapolare Richardson

Diferența față de adaptive simplu: extrapolare la final

Q1 = h/6*(fa + 4fc + fb) ← Simpson simplu Q2 = h/12*(fa + 4fd + 2fc + 4fe + fb) ← Simpson compus pe 2 panele if |Q2-Q1| < tol: return Q2 + (Q2-Q1)/15 ← extrapolare: anuleaza eroarea O(h^4)! else: recurse pe [a,c] si [c,b]

Extrapolarea (Q2-Q1)/15 este analogul Richardson — reduce eroarea cu un ordin. Aceasta este baza funcției MATLAB quadl.

LAB 11 — Cuadraturi de Tip Gauss

Principiul Cuadraturilor Gauss

Formula Gauss — grad maxim de exactitate

∫_a^b w(x)f(x)dx ≈ Σ_{k=1}^n Aₖ f(xₖ) + Rₙ(f)

Nodurile xₖ și coeficienții Aₖ sunt alesi ca formula să fie exactă pentru polinoame de grad ≤ 2n-1 (față de n-1 la Newton-Cotes)!

Cheia: xₖ = rădăcinile πₙ(x) ortogonal față de w pe [a,b] Aₖ = (πₙ, πₙ) / (πₙ'(xₖ) * πₙ₋₁(xₖ)) — coeficienți pozitivi
De ce graduri mai mari = mai puține noduri

Newton-Cotes cu n noduri: exact pe P_{n-1}. Gauss cu n noduri: exact pe P_{2n-1}.

Exemplu: int(-1,1) sin(x^2) dx cu toleranta 1e-7 Trapez n=1000 → ~10^-6 eroare Gauss-Legendre n=8 → ~10^-8 eroare ← de 125x mai puțini!

Generare Noduri prin Matricea Jacobi

Recurenta polinoamelor ortogonale π_{k+1}(x) = (x - αₖ)πₖ(x) - βₖπₖ₋₁(x) π₀ = 1, π₋₁ = 0 αₖ = (xπₖ, πₖ) / (πₖ, πₖ) βₖ = (πₖ, πₖ) / (πₖ₋₁, πₖ₋₁)
Matricea Jacobi Jₙ(w)

Tridiagonala simetrica n×n

⎡ α₀ √β₁ ⎤ Jₙ = ⎢ √β₁ α₁ √β₂ ⎥ ⎢ √β₂ α₂ √β₃ ⎥ ⎣ … αₙ₋₁ ⎦ Noduri: valorile proprii ale Jₙ (xₖ = λₖ) Coeficienti: Aₖ = β₀ · vₖ₁² (prima componentă a vectorului propriu)

Eroarea Formulei Gauss

Formula restului (dacă f ∈ C²ⁿ) Rₙ(f) = f⁽²ⁿ⁾(ξ)/(2n)! · ∫_a^b w(x)πₙ²(x)dx

Strategia pentru a determina n necesar:

  1. Majorează |f⁽²ⁿ⁾| ≤ M pe intervalul
  2. Calculează ∫w·πₙ² dx (din coeficienții de recurență)
  3. Crește n până când M/(2n)! · ∫w·πₙ² < ε

Prob 2 — Gauss-Legendre: ∫₋₁¹ sin(x²)dx și cos(x²)dx

Algoritm — creste n pana la convergenta
  1. Start cu n₀=5 noduri Legendre
  2. Calculează I_{n₀} = Σ wₖ f(xₖ)
  3. Crește n cu 1, calculează Iₙ
  4. Dacă |Iₙ - Iₙ₋₁| < 10⁻⁷ → stop
Rezultat n=8 noduri suficiente: ∫sin(x²)dx = 0.6205366034... (exact: 0.620536603...) ∫cos(x²)dx = 1.8090484758... (exact: 1.809048475...) Verificare eroare (Peano): f=sin(x²): |f^(16)(ξ)| ≤ max pe [-1,1] Restul ≤ 2.22×10⁻¹⁵ (sub precizia double!)

Prob 3 — Gauss-Chebyshev I: ∫₋₁¹ f(x)/√(1-x²)dx

Formula cu 10 noduri Noduri: xₖ = cos((2k-1)π/20), k=1,...,10 Ponderi: Aₖ = π/10 (toate egale!) ∫₋₁¹ cos(x)/√(1-x²) dx = π·J₀(1) = π·0.7651977... = 2.40393943... Calculat: vquad(nodes, w, @cos) = 2.40393943... Eroare: ~4×10⁻¹⁶ (precizie maximă!)
De ce eroarea e atât de mică?

cos(x) este analitică pe toată axa reală. Formula Chebyshev I cu 10 noduri este exactă pe P₁₉ și converge spectral pentru funcții analitice.

Prob 4 — Gauss-Chebyshev II: ∫₋₁¹ √(1-x²)f(x)dx

Formula cu 5 și 10 noduri ∫₋₁¹ √(1-x²)·cos(x) dx = π·J₁(1) = 1.382459... Cu 5 noduri (n=5): Noduri Cheb II: cos(kπ/5), k=1,...,5 Ponderi: π·sin²(kπ/5)/... (din matricea Jacobi cu α=0, β=π/2, 1/4,...) Eroare ≈ 4.1×10⁻¹⁰ Cu 10 noduri: eroare ~10⁻²⁰ (sub precizia double)

Prob 5 — Gauss-Laguerre: ∫₀∞ e⁻ˣ sin/cos(x)dx

Formula și valori exacte ∫₀∞ e⁻ˣ sin(x)dx = Im{1/(1-i)} = 1/2 ← exact! ∫₀∞ e⁻ˣ cos(x)dx = Re{1/(1-i)} = 1/2 ← exact! Noduri Laguerre L₆: rădăcinile lui L₆(x), ortogonal pe (0,∞) față de e⁻ˣ Coeficienți: calculați via matricea Jacobi (α=2k+1, β=k) Cu n=6: err sin ≈ 4.9×10⁻⁵ (insuficient) Cu n≈12: 8 zecimale exacte
Câte noduri sunt necesare? |sin^(12)(x)| ≤ 1 ∫₀∞ π₁₂²(x)e⁻ˣdx → calculat din coeficienti → Rₙ = M/(2n)! * ∫ < 5×10⁻⁹ pentru n ≈ 12-15

Prob 6 — Gauss-Hermite: ∫_ℝ e⁻ˣ² sin/cos(x)dx

Valori exacte (transformata Fourier a gaussianei) ∫_ℝ e⁻ˣ² cos(x)dx = √π · e⁻¹/⁴ ≈ 1.380388... ∫_ℝ e⁻ˣ² sin(x)dx = √π · e⁻¹/⁴ · sin(1/2) ≈ ... (Din formula: ∫_ℝ e⁻ˣ² e^{itx}dx = √π·e^{-t²/4}) Cu n=7 noduri Hermite: eroare ~7×10⁻¹⁰ ← 8 zecimale corecte!

Prob 7 — Gauss-Jacobi: ∫₀^(π/2) 1/√(sin x) dx

Problema — singularitate la x=0

sin(x) ≈ x la x=0 → 1/√(sin x) ≈ x^{-1/2} → integrabilă dar singulară. Gauss-Legendre ar converge lent. Soluție: Gauss-Jacobi cu ponderea corespunzătoare.

Substituția și alegerea formulei
  1. Substituție: x = π/4·(1+t), t ∈ [-1,1], dx = π/4·dt
  2. Integrala devine: π/4 · ∫₋₁¹ (sin(π(1+t)/4))^{-1/2} dt
  3. Singularitate la t=-1: sin(π(1+t)/4) ~ π(1+t)/4 → (1+t)^{-1/2}
  4. Alegem Gauss-Jacobi cu α=0, β=-1/2 (ponderea (1+t)^{-1/2})
  5. Integrandul: g(t) = π/4 · √((1+t)/sin(π(1+t)/4)) — MĂRGINIT la t=-1!
g(-1) → π/4·√(4/π) = √π/2 ≈ 0.886 (fara singularitate!) ∫₀^(π/2) 1/√(sin x) dx = Γ(1/4)·√π / (2·Γ(3/4)) ≈ 2.622... Cu ~15-20 noduri Jacobi(α=0, β=-1/2): 9 zecimale exacte
Valoarea exactă ∫₀^(π/2) sin(x)^(-1/2)dx = B(1/4, 1/2)/2 = Γ(1/4)·Γ(1/2)/(2·Γ(3/4)) = 2.622057554292119...
