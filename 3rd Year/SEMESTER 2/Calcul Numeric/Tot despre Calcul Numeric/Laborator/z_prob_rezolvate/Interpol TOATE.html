Teorema lui Peano

Definiție — Spațiul H_n[a,b]

Funcții suficient de regulate

Condiția: f ∈ Cn-1[a,b] și f(n-1) absolut continuă.

H_n[a,b] = { f : [a,b]→ℝ | f ∈ C^{n-1}[a,b], f^{(n-1)} absolut continuă }

Admite reprezentare Taylor cu rest integral:

f(x) = Σ_{k=0}^{n-1} f^(k)(a)·(x-a)^k/k! + ∫_a^x (x-t)^{n-1}/(n-1)! · f^(n)(t) dt
Puterea trunchiată

z₊ și extensia integralei la b

z₊ = { z, dacă z ≥ 0 { 0, dacă z < 0

Restul Taylor cu limita b (nu x):

R_{n-1}f(x) = 1/(n-1)! · ∫_a^b (x-t)₊^{n-1} · f^(n)(t) dt

Deoarece (x-t)₊=0 pentru t > x, limita se poate extinde la b.

Teorema 1 — Peano

Reprezentarea funcționalelor liniare

Fie L funcțională reală, continuă pe H_n[a,b], cu Ker L ⊇ P_{n-1}. Atunci:

Lf = ∫_a^b K(t) · f^(n)(t) dt

Nucleul Peano K:

K(t) = 1/(n-1)! · L[ (· - t)₊^{n-1} ]

L acționează în variabila x, cu t fix ca parametru. Demonstrație: L(T_{n-1}f)=0 deoarece T_{n-1}f ∈ P_{n-1} ⊆ Ker L; apoi continuitatea lui L permite comutarea cu integrala.

Corolarul 3

Când K(t) are semn constant

Dacă K(t) ≥ 0 (sau ≤ 0) pe [a,b] și f(n) continuă → ∃ ξ ∈ [a,b]:

Lf = 1/n! · f^(n)(ξ) · L(e_n)

e_n(x) = xn. Se aplică teorema de medie pentru integrale.

Exemplu 4 — Formula dreptunghiului

R(f) = ∫_a^b f dx − (b-a)·f((a+b)/2)

R se anulează pe P₁ → Ker(R)=P₁, n=2. Nucleul K(t) ≥ 0:

K(t) = { (t-a)²/2, t ≤ (a+b)/2 { (b-t)²/2, t > (a+b)/2

Aplicând corolarul (K ≥ 0 pe [a,b]):

R(f) = (b-a)³/24 · f″(ξ), ξ ∈ (a,b)

Interpolarea Lagrange

Problema: date noduri distincte {x₀,…,x_m} ⊂ [a,b] și valorile f(xₖ), găsiți unicul polinom P ∈ P_m cu P(xₖ)=f(xₖ).

Polinoamele fundamentale Lagrange

Baza ℓᵢ(x) — proprietatea Kronecker

ℓᵢ(x) = ∏_{j=0,j≠i}^m (x-xⱼ)/(xᵢ-xⱼ) ℓᵢ(xⱼ) = δᵢⱼ = { 1, dacă i=j ← valoarea 1 la nodul propriu { 0, dacă i≠j ← zero la celelalte noduri

ℓᵢ joacă același rol ca polinoamele fundamentale B-spline în spline liniare.

Teorema 5 — Existență și unicitate

Polinomul de interpolare Lagrange

(Lₘf)(x) = Σᵢ₌₀ᵐ f(xᵢ) · ℓᵢ(x)

Unicitate: dacă p* ∈ P_m cu p*(xᵢ)=f(xᵢ), atunci Lₘf-p* are m+1 rădăcini distincte → ≡ 0.

Matricea sistemului echivalent este Vandermonde (inversabilă).

Teorema 11 — Eroarea de interpolare

Expresia restului Rₘf(x)

Dacă f ∈ Cm+1[a,b], există ξ_x ∈ (α,β):

Rₘf(x) = uₘ(x)/(m+1)! · f^{(m+1)}(ξ_x) uₘ(x) = ∏ᵢ₌₀ᵐ (x-xᵢ) Marginea: |Rₘf(x)| ≤ Mₘ₊₁/(m+1)! · |uₘ(x)| Mₘ₊₁ = max |f^{(m+1)}| pe [a,b] Nucleul Peano: Kₘ(x;t) = 1/m! [(x-t)₊ᵐ - Σ ℓₖ(x)(xₖ-t)₊ᵐ]
Noduri Chebyshev — minimizarea erorii

Alegerea optimă a nodurilor

uₘ trebuie să fie polinomul monic Chebyshev de speta I de grad m+1. Nodurile Chebyshev pe [-1,1]:

xₖ = cos((2k+1)π/(2m+2)), k=0,…,m ‖Rₘf‖∞ ≤ ‖f^{(m+1)}‖∞ / (2ᵐ·(m+1)!) ← margine optimă

Nodurile uniforme pot produce fenomenul Runge pentru funcții ca 1/(1+x²) — divergență la marginile intervalului!

Metodele Aitken și Neville

Construiesc PIL incremental, prin relații de recurență, fără baza Lagrange explicită. Util când gradul necesar este necunoscut.

Propoziția 15 — Recurența Aitken

Formulă de recurență pentru PIL

P_{0,…,k}(x) = [(x-xⱼ)P_{0,…,ĵ,…,k} - (x-xᵢ)P_{0,…,î,…,k}] / (xᵢ-xⱼ)

Polinomul prin k+1 noduri se obține din doi polinoame prin k noduri.

Metoda Neville — notația Qᵢ,ⱼ

Tabelul triunghiular de interpolare

Qᵢ,₀ = f(xᵢ) Qᵢ,ⱼ = [(x-xᵢ₋ⱼ)·Qᵢ,ⱼ₋₁ - (x-xᵢ)·Qᵢ₋₁,ⱼ₋₁] / (xᵢ - xᵢ₋ⱼ)

Qᵢ,ⱼ = PIL prin nodurile x_{i-j},…,x_i evaluat în x. Diagonala Q_{i,i} convergentă!

Criteriu de oprire: |Q_{i,i} − Q_{i-1,i-1}| < ε. Nodurile se ordonează după |xᵢ-x|.

Metoda Baricentrică

Evaluare PIL în O(m) operații

wⱼ = 1 / ∏_{k≠j}(xⱼ-xₖ) = 1/u'ₘ(xⱼ) ℓⱼ(x) = uₘ(x) · wⱼ/(x-xⱼ)

Interpolarea Hermite

Teorema 23 — Existență și unicitate

Coincidența derivatelor până la ordinul rᵢ

Date m+1 noduri și ordine r₀,…,rₘ. Fie n = m + Σrᵢ. Există unic H_nf ∈ Pₙ:

(H_nf)^(ℓ)(xᵢ) = f^(ℓ)(xᵢ), 0≤ℓ≤rᵢ, 0≤i≤m

Unicitate: fiecare xᵢ e rădăcină de ordin rᵢ+1 → Σ(rᵢ+1) = n+1 > grad H_n → H_n≡0.

Metoda lui Powell

Ideea centrală — atribuire lui Powell

Dublarea nodurilor în secvența z

Date m+1 noduri distincte x₀,…,xₘ și valorile f(xᵢ), f'(xᵢ). Se construiește o secvență cu noduri duble:

z₀ = z₁ = x₀ z₂ = z₃ = x₁ ⋮ z₂ᵢ = z₂ᵢ₊₁ = xᵢ, i = 0, 1, …, m → 2(m+1) noduri total

Cheia: diferența dividată cu nod dublu este derivata (ca limită):

f[xᵢ, xᵢ] = lim_{t→xᵢ} [f(t)−f(xᵢ)]/(t−xᵢ) = f'(xᵢ)

Restul tabelei se calculează exact ca la DD standard — niciun caz special suplimentar! Metoda funcționează și pentru ordine de multiplicitate rᵢ ≥ 2 (triplu, etc.).

Convergența Interpolării + Fenomenul Runge

Interpolarea Lagrange de grad înalt cu noduri uniforme nu convergează în general. Există funcții continue pentru care eroarea → ∞ oriunde.

Exemplul 1 — Contraexemplul lui Runge (1901)

f(x)=1/(1+x²) pe [-5,5], noduri uniforme

lim_{m→∞} |f(x)-pₘ(x)| = { 0, dacă |x| < 3.633… { ∞, dacă |x| > 3.633…

f are poli complecși la z=±i. Oscilații violente la capete, chiar dacă f este analitică.

Exemplul 2 — Contraexemplul Bernstein

f(x)=|x| pe [-1,1], noduri uniforme

lim_{m→∞} |f(x)-Lₘ(f;x)| = ∞, ∀x ∈ [-1,1] (exceptând x=-1,0,1)

f NU este derivabilă în x=0. Și distribuția uniformă e de vină — noduri Chebyshev converge!

Soluție 1 — Noduri Chebyshev

Minimizează ‖uₘ‖∞ → eroare minimă

‖Rₘf‖ ≤ ‖f^{(m+1)}‖∞ / (2ᵐ·(m+1)!) ← față de 1/(m+1)! cu uniforme
Soluție 2 — Interpolare pe porțiuni (SPLINE)

Polinoame de grad MIC pe subintervale MICI

Pe intervale suficient de mici, orice funcție poate fi aproximată arbitrar de bine prin polinoame de grad mic (chiar 0 sau 1). Converge sigur cu |Δ|→0.

Spații Spline Skm(Δ)

Definiție — Spline polinomial

Funcții pe porțiuni cu regularitate impusă

Fie Δ: a=x₁ < x₂ < … < xₙ=b o subdiviziune a lui [a,b].

S^k_m(Δ) = { s : s ∈ C^k[a,b], s|_{[xᵢ,xᵢ₊₁]} ∈ Pₘ, i=1,…,n-1 }

m = gradul polinomului pe fiecare porțiune  |  k = clasa de netezime (k=-1 permite discontinuități).

Spline Liniare + Funcții B-Spline

Spline liniare de interpolare

s ∈ S⁰₁(Δ) cu s(xᵢ)=f(xᵢ)

Pe fiecare interval [xᵢ,xᵢ₊₁]:

s(f;x) = fᵢ + (x-xᵢ)·f[xᵢ,xᵢ₊₁]

Eroarea locală:

|f(x)-s(f;x)| ≤ (Δxᵢ)²/8 · max|f''|

Eroarea globală:

‖f-s‖∞ ≤ 1/8 · |Δ|² · ‖f''‖∞
Funcțiile B-Spline de grad 1 — "Pălăria chinezească"

Baza lui S⁰₁(Δ)

Cu x₀=x₁, xₙ₊₁=xₙ (noduri fictive la capete):

Bᵢ(x) = { (x-xᵢ₋₁)/(xᵢ-xᵢ₋₁), xᵢ₋₁≤x≤xᵢ { (xᵢ₊₁-x)/(xᵢ₊₁-xᵢ), xᵢ≤x≤xᵢ₊₁ { 0, altfel Bᵢ(xⱼ) = δᵢⱼ ← proprietatea Kronecker! dim S⁰₁(Δ) = n ← n funcții de bază

Spline Cubice C¹ — Interpolarea Hermite pe Porțiuni

Vrem s ∈ S¹₃(Δ) cu s(xᵢ)=fᵢ și s'(xᵢ)=mᵢ. Alegem mᵢ = f'(xᵢ) (derivatele cunoscute).

Forma Newton a lui pᵢ(x) pe [xᵢ,xᵢ₊₁]

Cubicul Hermite local

pᵢ(x) = cᵢ,₀ + cᵢ,₁(x-xᵢ) + cᵢ,₂(x-xᵢ)² + cᵢ,₃(x-xᵢ)³ cᵢ,₀ = fᵢ cᵢ,₁ = mᵢ cᵢ,₂ = [3f[xᵢ,xᵢ₊₁] - 2mᵢ - mᵢ₊₁] / hᵢ (hᵢ = xᵢ₊₁-xᵢ) cᵢ,₃ = [mᵢ + mᵢ₊₁ - 2f[xᵢ,xᵢ₊₁]] / hᵢ²
Eroarea locală

Precizie O(|Δ|⁴)

|f(x)-pᵢ(x)| ≤ hᵢ⁴/2 · max|f⁽⁴⁾| / 4! = hᵢ⁴/48 · max|f⁽⁴⁾|
Eroarea globală (Eq. 18)

Convergență de ordin 4

‖f-s₃‖∞ ≤ 1/384 · |Δ|⁴·‖f⁽⁴⁾‖∞ ‖f-s₃‖∞ = O(n⁻⁴), n→∞ (față de O(n⁻²) pentru spline liniare!)

Avantaj: schemă strict locală — fiecare porțiune se determină independent. Dezavantaj: necesită valorile derivatei f'(xᵢ).

Spline Cubice C² — Sistemul Tridiagonal

Cerem s₃ ∈ S²₃(Δ): continuitatea derivatei de ordin II. Condițiile p''ᵢ₋₁(xᵢ)=p''ᵢ(xᵢ) generează un sistem liniar.

Sistemul tridiagonal pentru m₁,…,mₙ (Eq. 21-22)

n-2 ecuații interioare

Δxᵢ·mᵢ₋₁ + 2(Δxᵢ₋₁+Δxᵢ)·mᵢ + Δxᵢ₋₁·mᵢ₊₁ = bᵢ, i=2,…,n-1 bᵢ = 3{ Δxᵢ·f[xᵢ₋₁,xᵢ] + Δxᵢ₋₁·f[xᵢ,xᵢ₊₁] } Δxᵢ = xᵢ₊₁ - xᵢ (pasul local)

n-2 ecuații, n necunoscute → 2 ecuații suplimentare la capete. Sistemul complet este tridiagonal → rezolvare eficientă prin eliminare Gauss (Thomas algorithm).

Spline Complete (Racordate)

m₁=f'(a), mₙ=f'(b)

Derivatele la capete sunt prescrise. Cel mai precis.

‖f^(r) - s^(r)‖∞ ≤ cᵣ·|Δ|^{4-r}·‖f⁽⁴⁾‖∞ c₀=5/384, c₁=1/24, c₂=3/8
Spline Naturale

s''(a)=s''(b)=0

Fără informație despre derivate. Ecuații adiționale:

2m₁ + m₂ = 3f[x₁,x₂] mₙ₋₁ + 2mₙ = 3f[xₙ₋₁,xₙ]

Atenție: precizie O(|Δ|²) near capete (dacă f''(a)≠0)!

Spline Naturale — ecuații adiționale cu f'' (Eq. 24)

s''(a)=f''(a), s''(b)=f''(b)

2m₁ + m₂ = 3f[x₁,x₂] - ½f''(a)·Δx₁ mₙ₋₁ + 2mₙ = 3f[xₙ₋₁,xₙ] + ½f''(b)·Δxₙ₋₁

Păstrează structura tridiagonală. Precizie O(|Δ|⁴) pretutindeni.

Not-a-Knot Spline (C. de Boor)

p₁≡p₂ și pₙ₋₂≡pₙ₋₁ → x₂ și xₙ₋₁ inactive

Impunem continuitatea lui s'''₃ în x₂ și xₙ₋₁ → c₁,₃=c₂,₃ și cₙ₋₂,₃=cₙ₋₁,₃. Ecuații:

Δx₂·m₁ + (Δx₂+Δx₁)·m₂ = γ₁ (Δxₙ₋₁+Δxₙ₋₂)·mₙ₋₁ + Δxₙ₋₂·mₙ = γ₂

Sistemul devine tridiagonal după transformări. Implicit în MATLAB spline(). Nu necesită derivate la capete dar menține precizie O(|Δ|⁴).

Proprietatea de Minimalitate a Spline Cubice

Spline-ul cubic complete și natural minimizează curbura totală ∫[g''(x)]² dx — analogia cu o vergea fizică flexibilă.

Teorema 3 — Spline complete (pe Δ')

Norma minimă a derivatei II

Δ': capetele sunt noduri duble (se interpolează și valorile și derivatele la a, b). Pentru orice g ∈ C²[a,b] care interpolează f pe Δ':

∫_a^b [g''(x)]² dx ≥ ∫_a^b [s''_compl(f;x)]² dx

Cu egalitate dacă și numai dacă g = s_compl. Demonstrație: se arată că ∫s''(g''-s'')dx = 0 (integrare prin părți + s''' constantă pe porțiuni).

Teorema 5 — Spline naturale (pe Δ)

Cel mai neted interpolant (fără derivate la capete)

Pentru orice g ∈ C²[a,b] ce interpolează f pe Δ:

∫_a^b [g''(x)]² dx ≥ ∫_a^b [s''_nat(f;x)]² dx

Consecință: comparând cele două teoreme:

∫[s''_compl]² dx ≥ ∫[s''_nat]² dx

Spline-ul cubic natural este cel mai neted interpolant (în sensul că ‖s''‖_{L²} este minimă). Spline-ul complet e mai precis numeric dar mai puțin "neted".

Motivul numelui "spline"

Vergeaua de desen — analogia fizică

Un spline fizic (vergea flexibilă de lemn sau metal trecută prin puncte fixe cu "raci") ia forma ce minimizează energia potențială:

E = ∫_a^b [g''(x)]² / (1+[g'(x)]²)^{3/2} dx ← curbura exactă

Pentru variații lente (‖g'‖∞ ≪ 1), aceasta aproximează ∫[g'']² dx — exact proprietatea din Teorema 5.

Termenul "spline" vine din scandinavă: "spon" = pană de lemn. Folosit în naval design și aeronautică înainte de era computerelor.
