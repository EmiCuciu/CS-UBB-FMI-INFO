Metoda Newton-Raphson (Tangentei)

Idee geometrică

Înlocuieste f cu tangenta sa în punctul curent → intersecție cu axa Ox

x_{n+1} = x_n - f(x_n) / f'(x_n)

f(x) ≈ f(xₙ) + f'(xₙ)·(x-xₙ) → zero când x = xₙ - f(xₙ)/f'(xₙ)

Algoritm Intrare: f, f', x0, ε, Nmax Pentru k=1,...,Nmax: x = x0 - f(x0)/f'(x0) dacă |x-x0| < ε: return x x0 = x Eșec: iteratii depășite
Convergenta

Pătratică: eₙ₊₁ ≈ C·eₙ²

C = f''(α) / (2f'(α)) → nr. zecimale corecte se DUBLEAZA la fiecare iteratie! 5 iteratii → 2^5 = 32 zecimale

Conditie: f'(α) ≠ 0 (rădăcină simplă). La rădăcini multiple → convergentă liniară.

Metoda Secantei

Idee — Newton fara derivata

Înlocuieste f'(xₙ) cu panta secantei prin (xₙ₋₁, xₙ)

x_{n+1} = x_n - f(x_n) · (x_n - x_{n-1}) / (f(x_n) - f(x_{n-1}))

Necesită două valori de start x₀, x₁ (spre deosebire de Newton care necesită o singura).

Avantaje vs Newton
  • Nu necesită derivata analitică
  • O singură evaluare f per iteratie (vs 2 la Newton: f și f')
  • Util când f' e greu de calculat
Dezavantaje
  • Convergentă superlinară: eₙ₊₁ ≈ C·eₙ^φ, φ≈1.618 (numărul de aur)
  • Mai lentă decât Newton
  • Poate diverge dacă x₀, x₁ sunt prost aleși

Metoda Aproximațiilor Succesive (MAS)

Punct fix

Rescrie f(x)=0 ca x=g(x), iterează x_{n+1} = g(xₙ)

Exemple de rescriere pentru f(x)=cos(x)-x=0: g(x) = cos(x) → x = cos(x) Pentru f(x) = x^3+4x^2-10 = 0: g(x) = sqrt(10/(x+4)) → x = sqrt(10/(x+4))
Teorema punctului fix (Banach)

MAS converge dacă |g'(x)| ≤ L < 1 pe intervalul relevant

eₙ₊₁ = g(xₙ) - g(α) ≈ g'(ξ)·eₙ Convergenta LINIARA: |eₙ| ≤ Lⁿ·|e₀| Rata de convergenta: L = |g'(α)| Daca L = 0 → convergenta patratica (ca Newton!) Daca L ≥ 1 → divergenta

Metoda lui Steffensen (Accelerare Aitken Δ²)

Idea — accelereaza MAS la convergenta patratica

Aplică formula Aitken Δ² pe 3 iterații consecutive

p1 = g(p0) p2 = g(p1) (p1 - p0)² p = p0 - ----------- ← formula Aitken Δ² p2 - 2p1 + p0
De ce functioneaza?

Dacă MAS converge liniar: eₙ₊₁ ≈ L·eₙ, atunci:

p1-p0 ≈ L·e0, p2-p1 ≈ L²·e0 Aitken elimina termenul liniar → convergenta patratica!
Avantaj cheie

Convergentă pătratică fără a calcula derivata, spre deosebire de Newton care necesită f'(x).

Steffensen = Newton implicit fară derivată.

Sisteme de Ecuatii Neliniare — Metoda Newton

Generalizare în R^n

f: R^n → R^n, cauta x cu f(x) = 0

x^{(n+1)} = x^{(n)} - [J(x^{(n)})]^{-1} · f(x^{(n)})

J(x) = Jacobianul lui f în x (matrice n×n a derivatelor parțiale).

În practică: nu calculăm inversa, rezolvăm sistemul linear J(xₙ)·Δ = f(xₙ), apoi xₙ₊₁ = xₙ - Δ.

Jacobianul — cum se calculeaza f = [f1(x,y); f2(x,y)] J = [df1/dx df1/dy] [df2/dx df2/dy]
MAS pentru sisteme phi(x) = x - Lambda · f(x) Lambda = -[J(x0)]^{-1} (fix!) Convergenta liniara (raza spectrala a phi'(x*) < 1 necesara)

Sistem 2D — Newton pe foaie

Sistemul f1(x,y) = x² + y² - 1 = 0 f2(x,y) = x³ - y = 0 Jacobian: J(x,y) = [2x, 2y ] [3x², -1 ]
Iteratia Newton — start (x0, y0) = (0.8, 0.6)
  1. f([0.8; 0.6]) = [0.64+0.36-1; 0.512-0.6] = [0; -0.088] (f1=0 exact pt acest x0!)
  2. J([0.8; 0.6]) = [1.6, 1.2; 1.92, -1]
  3. Rezolvam J·Δ = f: [1.6, 1.2; 1.92, -1]·[Δx; Δy] = [0; -0.088]
  4. det(J) = 1.6·(-1) - 1.2·1.92 = -1.6 - 2.304 = -3.904
  5. Δx = (0·(-1) - 1.2·(-0.088))/(-3.904) = 0.1056/(-3.904) = -0.02705
  6. Δy = (1.6·(-0.088) - 0·1.92)/(-3.904) = -0.1408/(-3.904) = 0.03607
  7. x1 = [0.8-(-0.02705); 0.6-0.03607] = [0.82705; 0.56393]
