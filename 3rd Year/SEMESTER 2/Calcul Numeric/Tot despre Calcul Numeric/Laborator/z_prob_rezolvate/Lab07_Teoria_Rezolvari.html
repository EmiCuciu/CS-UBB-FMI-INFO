Forma Clasică a Interpolării Lagrange

Definiție — Polinomul de Interpolare Lagrange (PIL)

Problema: date m+1 noduri distincte și valorile f

Fie x₀, x₁, ..., x_m ∈ [a,b] distincte și f(x₀), ..., f(x_m). Există un unic polinom L_mf ∈ P_m cu:

(L_m f)(x_k) = f(x_k), k = 0, 1, ..., m

Dat de formula:

(L_m f)(x) = Σ_{k=0}^m f(x_k) · ℓ_k(x)
Polinoamele fundamentale ℓ_k

Proprietatea Kronecker

ℓ_k(x) = ∏_{j=0, j≠k}^m (x-x_j)/(x_k-x_j) ℓ_k(x_j) = δ_kj = { 1, j=k { 0, j≠k

Grad(ℓ_k) = m. Suma Σℓ_k(x) = 1 (partiție a unității).

Complexitate

Costuri computaționale

Evaluare ℓ_k(x): 2(m-1) înmulțiri 1 împărțire 2m scăderi Total (L_m f)(x): O(m²) operații per punct Actualizare nod nou: recalculare completă!

Eroarea de Interpolare

Teorema — Restul R_m f

Formula erorii exacte

Dacă f ∈ C^{m+1}[α,β], pentru orice x ∃ξ ∈ (α,β):

R_m f(x) = f(x) - (L_m f)(x) = u_m(x)/(m+1)! · f^{(m+1)}(ξ)

unde u_m(x) = (x-x₀)(x-x₁)···(x-x_m) și α=min{x,x₀,...,x_m}, β=max{...}

Marginea erorii

Estimare practică

|R_m f(x)| ≤ M_{m+1}/(m+1)! · |u_m(x)| M_{m+1} = max_{[a,b]} |f^{(m+1)}(x)|

Valabilă chiar dacă nu cunoaștem ξ exact.

Logică de gândire

Cum să calculezi eroarea

  1. Identifică f^{(m+1)}(x) — derivata de ordin m+1
  2. Estimează M_{m+1} = max|f^{(m+1)}| pe intervalul relevant
  3. Calculează |u_m(x)| = ∏|x-x_k|
  4. Aplică formula: |err| ≤ M/(m+1)! · |u_m|

Forma Baricentrică

Ideea cheie — de ce baricentrică?

Dezavantajele formei clasice

Forma clasică: O(m²) per evaluare, instabilă numeric, actualizare completă la nod nou. Soluția: se rescrie cu ponderi independente de x.

Construcție Pas cu Pas

De la clasic la baricentric

  1. Definim ℓ(x) = (x-x₀)(x-x₁)···(x-x_m) → ℓ_j(x) = ℓ(x)/(x-x_j)
  2. Ponderi baricentrice: w_j = 1/∏_{k≠j}(x_j-x_k) = 1/ℓ'(x_j)
  3. Forma I (îmbunătățită): p(x) = ℓ(x)·Σ_j [w_j/(x-x_j)]·f_j
  4. Interpolând constanta 1: 1 = ℓ(x)·Σ_j [w_j/(x-x_j)]
  5. Împărțind: ℓ(x) se simplifică → Forma II (baricentrică):
p(x) = [ Σ_j w_j/(x-x_j) · f_j ] / [ Σ_j w_j/(x-x_j) ]
Avantaje Forma Baricentrică

De ce e mai bună

Calculul w_j: O(m²) o singura dată Evaluare p(x): O(m) per punct Nod nou xm+1: fiecare w_j /= (x_j - x_{m+1}) calculezi w_{m+1} cost: O(m)
Caz special xx(i) = x(j)

Evitarea împărțirii la 0

if xx(i) == x(j): p(xx(i)) = f(j) ← direct! (termenii w_j/(xx-x_j) → ∞ dar se simplifica corect)

Implementarea trebuie să trateze explicit acest caz.

Noduri Chebyshev — Ponderi Explicite

Motivație

De ce Chebyshev? → Minimizarea ‖u_m‖∞

Eroarea: |R_mf| ≤ M_{m+1}/(m+1)! · |u_m(x)|. Nodurile Chebyshev minimizează max|u_m(x)| pe [-1,1].

min ‖u_m‖∞ = 1/2^m (atins de T̃_{m+1}: polinomul Chebyshev monic)
Chebyshev Speta I

Noduri + ponderi baricentrice

x_k = cos((2k+1)π/(2m+2)) pe [-1,1] k = 0, 1, ..., m w_k = (-1)^k · sin((2k+1)π/(2m+2)) Pe [a,b]: x̃_k = (a+b)/2 + (b-a)/2·x_k

Nu include capetele ±1.

Chebyshev Speta II

Noduri + ponderi baricentrice

x_k = cos(kπ/m) pe [-1,1] k = 0, 1, ..., m δ_k = ½ dacă k=0 sau k=m, altfel 1 w_k = (-1)^k · δ_k Pe [a,b]: x̃_k = (a+b)/2 + (b-a)/2·x_k

Include capetele ±1. Optim pentru FFT (chebfun).

Problema 1 — Rutina de evaluare PIL (my_lagrange_eval)

Cerință

Implementați evaluarea PIL când se dau punctele, nodurile și valorile

Algoritmul — Pseudocod

Complexitate O(m²) per punct

Intrare: x[0..m], y[0..m], puncte xx[0..n-1] Ieșire: yy[0..n-1] = (L_m f)(xx[i]) Pentru fiecare xx[i]: s ← 0 Pentru k = 0 până la m: ℓk ← 1 Pentru j = 0 până la m (j ≠ k): ℓk ← ℓk * (xx[i] - x[j]) / (x[k] - x[j]) s ← s + y[k] * ℓk yy[i] ← s
Exemplu numeric — pe foaie

f(x) = sin(x), noduri x₀=0, x₁=π/4, x₂=π/2 (m=2), evaluare x=π/6

  1. Valori: f(0)=0, f(π/4)=√2/2≈0.7071, f(π/2)=1
  2. ℓ₀(π/6) = (π/6−π/4)(π/6−π/2) / (0−π/4)(0−π/2) = (−π/12)(−π/3) / (−π/4)(−π/2) = (π²/36)/(π²/8) = 8/36 = 2/9 ≈ 0.2222
  3. ℓ₁(π/6) = (π/6−0)(π/6−π/2) / (π/4−0)(π/4−π/2) = (π/6)(−π/3) / (π/4)(−π/4) = (−π²/18)/(−π²/16) = 16/18 = 8/9 ≈ 0.8889
  4. ℓ₂(π/6) = (π/6−0)(π/6−π/4) / (π/2−0)(π/2−π/4) = (π/6)(−π/12) / (π/2)(π/4) = (−π²/72)/(π²/8) = −1/9 ≈ −0.1111
  5. Verificare: 2/9 + 8/9 + (−1/9) = 9/9 = 1 ✓
(L₂f)(π/6) = 0·(2/9) + (√2/2)·(8/9) + 1·(−1/9) = 0 + 4√2/9 − 1/9 = (4√2 − 1)/9 ≈ (5.6569 − 1)/9 ≈ 4.6569/9 ≈ 0.5174 sin(π/6) = 0.5000 → eroare ≈ 0.0174

Problema 2 — Polinoamele Fundamentale

Cerință

Reprezentați grafic ℓ_k pentru grad dat și noduri date

Logică de gândire

Proprietăți cheie ale ℓ_k

  1. ℓ_k are grad m (m+1 noduri → m factori la numărător)
  2. ℓ_k(x_j) = δ_kj → la nodul propriu valoarea e 1, la celelalte e 0
  3. Suma Σ_k ℓ_k(x) = 1 pentru orice x (partiție a unității)
  4. Evaluează ℓ_k pe o grilă fină cu my_lagrange_basis, plotează
Exemplu pe foaie — m=2, x₀=−1, x₁=0, x₂=1

Calculul formulelor explicite

ℓ₀(x) = (x−0)(x−1) / ((−1−0)(−1−1)) = x(x−1) / (−1)(−2) = x(x−1)/2 ℓ₁(x) = (x−(−1))(x−1) / (0−(−1))(0−1) = (x+1)(x−1) / (1)(−1) = −(x²−1) = 1−x² ℓ₂(x) = (x−(−1))(x−0) / (1−(−1))(1−0) = x(x+1) / (2)(1) = x(x+1)/2 Verificare în x=0.5: ℓ₀(0.5) = (0.5)(−0.5)/2 = −0.125 ℓ₁(0.5) = 1−0.25 = 0.75 ℓ₂(0.5) = (0.5)(1.5)/2 = 0.375 Suma = −0.125 + 0.75 + 0.375 = 1.0 ✓

Problema 3 — Grafic f și L_mf

Cerință

Plot f și L_mf pe același grafic pentru diverse grade m

Strategia

Ce observăm pe grafic

  1. Alege f cunoscută (sin, 1/(1+x²), eˣ)
  2. Generează noduri uniforme sau Chebyshev
  3. Evaluează L_mf pe o grilă fină (500+ puncte)
  4. Plot f cu linie neagră groasă, L_mf cu culori diferite per m
  5. Mărește m → observi convergența (sau divergența la Runge!)
Nota despre Runge

De ce e importantă alegerea nodurilor

Pentru f(x)=1/(1+x²) pe [−5,5], interpolarea cu noduri uniforme diverge la margini (|x|>3.633). Cu noduri Chebyshev convergează uniform.

Noduri uniforme m=16: max|err| >> 1 (divergenta!) Noduri Chebyshev m=16: max|err| < 10^{-6} (convergenta!)

Problema 5 — Metoda Baricentrică

5a — Caz general: calculul w_j și evaluarea p(x)

Algoritm complet
PASUL 1 — Calculul ponderilor (O(m²), o singura dată): Pentru j = 0 până la m: w[j] ← 1 Pentru k = 0 până la m (k ≠ j): w[j] ← w[j] · (x[j] - x[k]) w[j] ← 1/w[j] PASUL 2 — Evaluare în x (O(m) per punct): numer ← 0, denom ← 0 Pentru j = 0 până la m: dacă x == x[j]: return f[j] ← exact pe nod tmp ← w[j] / (x - x[j]) numer ← numer + tmp · f[j] denom ← denom + tmp return numer/denom
Exemplu numeric — pe foaie: m=2, x₀=0, x₁=1, x₂=2

Calcul ponderi w_j

  1. w₀ = 1/((x₀−x₁)(x₀−x₂)) = 1/((0−1)(0−2)) = 1/(2) = 0.5
  2. w₁ = 1/((x₁−x₀)(x₁−x₂)) = 1/((1−0)(1−2)) = 1/(−1) = −1
  3. w₂ = 1/((x₂−x₀)(x₂−x₁)) = 1/((2−0)(2−1)) = 1/(2) = 0.5
Evaluare f(x)=eˣ la x=0.5 (cu y₀=1, y₁=e, y₂=e²): diff = [0.5-0, 0.5-1, 0.5-2] = [0.5, -0.5, -1.5] tmp = [0.5/0.5, -1/-0.5, 0.5/-1.5] = [1, 2, -0.333] numer = 1·1 + 2·e + (-0.333)·e² = 1 + 5.436 - 2.463 = 3.973 denom = 1 + 2 + (-0.333) = 2.667 p(0.5) = 3.973/2.667 = 1.4898 e^0.5 = 1.6487 → eroare ≈ 0.16 (m=2, echidistant, de așteptat)

5b,c — Chebyshev I și II: ponderi explicite

Chebyshev I — m=3 pe [-1,1]

Calcul explicit w_k

k = 0,1,2,3 x_k = cos((2k+1)π/8) x₀=cos(π/8) ≈ 0.924 x₁=cos(3π/8) ≈ 0.383 x₂=cos(5π/8) ≈ -0.383 x₃=cos(7π/8) ≈ -0.924 w_k = (-1)^k·sin((2k+1)π/8): w₀ = sin(π/8) ≈ 0.383 w₁ = -sin(3π/8) ≈ -0.924 w₂ = sin(5π/8) ≈ 0.924 w₃ = -sin(7π/8) ≈ -0.383
Chebyshev II — m=3 pe [-1,1]

Calcul explicit w_k

k = 0,1,2,3 x_k = cos(kπ/3): x₀=cos(0)=1, x₁=cos(π/3)=0.5 x₂=cos(2π/3)=-0.5, x₃=cos(π)=-1 δ = [1/2, 1, 1, 1/2] w_k = (-1)^k · δ_k: w₀ = +0.5 w₁ = -1 w₂ = +1 w₃ = -0.5
De ce Chebyshev II e special

Proprietăți remarcabile

  1. Ponderile au formă simplă: {½, −1, +1, −1, ..., ±½} → ușor de calculat
  2. Includ capetele intervalului (x₀=b, x_m=a) → interpolare cu valori la capete
  3. Compatibil cu FFT → evaluare în O(m·log(m)) cu chebfun
  4. Convergent spectral pentru funcții analitice: ‖err‖ = O(C^{−m}), C > 1

Contraexemplele Runge și Bernstein

Contraexemplul Runge (1901)

f(x) = 1/(1+x²) pe [-5,5], noduri uniforme

lim_{m→∞} |f(x) - p_m(x)| = { 0, dacă |x| < 3.633... { ∞, dacă |x| > 3.633... Cauza: f are poli complecși z = ±i, apropiați de intervalul real [-5,5]. Distribuția uniformă amplifică erorile la margine prin oscilații.

Soluție: noduri Chebyshev → convergent pretutindeni pe [-5,5].

Contraexemplul Bernstein

f(x) = |x| pe [-1,1], noduri uniforme

lim_{m→∞} |f(x) - L_m(f;x)| = ∞ ∀x ∈ [-1,1] (exceptând x=-1,0,1) Cauza: f nu e derivabilă în x=0 (colț = derivată discontinuă). Noduri uniforme nu ajută. Cu noduri Chebyshev: convergența se îmbunătățește dar rămâne lentă (O(1/m) pentru funcții cu colț).
