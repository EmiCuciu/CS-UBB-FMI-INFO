Spline Cubic S²₃(Δ)

Definiție

Funcție pe porțiuni, C²[a,b], cubică pe fiecare interval

Fie Δ: x₁ < x₂ < … < xₙ. Un spline cubic este s ∈ C²[a,b] cu s|_{[xᵢ,xᵢ₊₁]} ∈ P₃.

Condiții de interpolare: s(xᵢ) = f(xᵢ), i=1,…,n. Avem n-1 cubice × 4 coef = 4(n-1) parametri, și (n-2)×3 condiții de continuitate C² + n condiții de interpolare → n+2 grade de libertate → 2 condiții la capete.

Coeficienții Taylor pe Intervale

Forma locală (Taylor în xᵢ)

pe intervalul [xᵢ, xᵢ₊₁], cu hᵢ = xᵢ₊₁ − xᵢ

s(x) = c₄ + c₃·(x-xᵢ) + c₂·(x-xᵢ)² + c₁·(x-xᵢ)³ Fie mᵢ = s'(xᵢ) și f[xᵢ,xᵢ₊₁] = (fᵢ₊₁-fᵢ)/hᵢ Atunci: c₄ = fᵢ c₃ = mᵢ c₂ = (3·f[xᵢ,xᵢ₊₁] - 2mᵢ - mᵢ₊₁) / hᵢ c₁ = (mᵢ + mᵢ₊₁ - 2·f[xᵢ,xᵢ₊₁]) / hᵢ²

Odată rezolvat sistemul pentru m₁,…,mₙ, coeficienții se calculează direct.

Sistemul Tridiagonal pentru mᵢ

Ecuațiile interioare (continuitatea s'')

Condiția p''ᵢ₋₁(xᵢ) = p''ᵢ(xᵢ) pentru i=2,…,n-1:

hᵢ·mᵢ₋₁ + 2(hᵢ₋₁+hᵢ)·mᵢ + hᵢ₋₁·mᵢ₊₁ = bᵢ bᵢ = 3·(hᵢ·f[xᵢ₋₁,xᵢ] + hᵢ₋₁·f[xᵢ,xᵢ₊₁]) hᵢ = xᵢ₊₁ - xᵢ

Sistemul complet este tridiagonal → rezolvare eficientă O(n) cu algoritmul Thomas.

Tipuri de Spline — Condiții la Capete

Tip 0 — Complet (Clamped)

s'(a) = f'(a), s'(b) = f'(b)

Prima ecuatie: m₁ = f'(a) Ultima ecuatie: mₙ = f'(b)

Cel mai precis: O(h⁴). Necesită f'(a) și f'(b).

Tip 1 — Derivate secunde

s''(a) = f''(a), s''(b) = f''(b)

Prima: 2m₁ + m₂ = 3f[x₁,x₂] - h₁/2·f''(a) Ultima: mₙ₋₁ + 2mₙ = 3f[xₙ₋₁,xₙ] + hₙ/2·f''(b)

Precizie O(h⁴). Necesită f''(a) și f''(b).

Tip 2 — Natural

s''(a) = s''(b) = 0

Tip 1 cu f''(a) = f''(b) = 0: Prima: 2m₁ + m₂ = 3f[x₁,x₂] Ultima: mₙ₋₁ + 2mₙ = 3f[xₙ₋₁,xₙ]

Cel mai neted (∫s''²dx minimal). Precizie O(h²) la capete. Nu necesită derivate.

Tip 3 — Not-a-Knot (deBoor)

s'''continuă în x₂ și xₙ₋₁

Impune p₁ ≡ p₂ și pₙ₋₂ ≡ pₙ₋₁ (primele două cubice identice, ultimele două identice) Precizie O(h⁴). Nu necesită derivate. Folosit implicit în MATLAB spline().

Evaluarea Spline-ului (Schema Horner)

Pe intervalul [xₖ, xₖ₊₁]

Schema Horner pentru evaluare eficientă O(n)

s = t - xₖ (distanta pana la nodul stang) z = c₄ + s*(c₃ + s*(c₂ + s*c₁)) (Horner: 3 inmultiri, 3 adunari)

Localizarea intervalului: binar search sau scanare liniară.

Spline Parametric (Prob 2 și 3)

Idee — două spline independente

Curba (x(t), y(t)) parametrizată cu t = 0, 1, ..., N-1

  1. Date: puncte (x₁,y₁), ..., (xₙ,yₙ) în plan
  2. Parametru: t = 0, 1, ..., N-1 (index simplu)
  3. Calculează coeficienți pentru x(t): cx = my_cubic_spline(t, x, 2)
  4. Calculează coeficienți pentru y(t): cy = my_cubic_spline(t, y, 2)
  5. Evaluează pe grilă fină tt: xx=my_eval_spline(t,cx,tt); yy=my_eval_spline(t,cy,tt)
  6. Plot (xx, yy) → curba netedă prin toate punctele

Funcționează pentru orice curbă plană, inclusiv curbe închise (dacă primul și ultimul punct coincid).

Problema 1 — Coeficienți + Evaluare

Funcții MATLAB c = my_cubic_spline(x, f, type, der) % coeficienti z = my_eval_spline(x, c, t) % evaluare

Rezolvare pe foaie — exemplu simplu

Date: n=3 noduri, spline natural

x = [0, 1, 2], f = [0, 1, 0] → s''(0)=s''(2)=0

Pasul 1 — Diferente dividate și pași h₁ = x₂-x₁ = 1, h₂ = x₃-x₂ = 1 f[x₁,x₂] = (1-0)/1 = 1 f[x₂,x₃] = (0-1)/1 = -1
Pasul 2 — Sistemul 3×3 (natural: s''=0 la capete) Ecuatia 1 (cap. stang, natural): 2m₁ + m₂ = 3·f[x₁,x₂] = 3 Ecuatia 2 (interioara): h₂·m₁ + 2(h₁+h₂)·m₂ + h₁·m₃ = 3(h₂·f[x₁,x₂] + h₁·f[x₂,x₃]) 1·m₁ + 4·m₂ + 1·m₃ = 3(1·1 + 1·(-1)) = 0 Ecuatia 3 (cap. drept, natural): m₂ + 2m₃ = 3·f[x₂,x₃] = -3 Sistemul: [2 1 0] [m₁] [3 ] [1 4 1] [m₂] = [0 ] [0 1 2] [m₃] [-3] Solutie: m₁ = 3/2, m₂ = 0, m₃ = -3/2
Pasul 3 — Coeficienții pe [x₁,x₂]=[0,1] c₄ = f(0) = 0 c₃ = m₁ = 3/2 c₂ = (3·f[0,1] - 2m₁ - m₂)/h₁ = (3·1 - 3 - 0)/1 = 0 c₁ = (m₁ + m₂ - 2·f[0,1])/h₁² = (3/2 + 0 - 2)/1 = -1/2 s(x) = 0 + (3/2)x + 0·x² + (-1/2)x³ = 3x/2 - x³/2 pe [0,1] Verificare: s(0)=0 ✓, s(1)=3/2-1/2=1 ✓, s'(0)=3/2=m₁ ✓
Pasul 3b — Coeficienții pe [x₂,x₃]=[1,2] c₄ = f(1) = 1 c₃ = m₂ = 0 c₂ = (3·f[1,2] - 2m₂ - m₃)/h₂ = (3·(-1) - 0 + 3/2)/1 = -3/2 c₁ = (m₂ + m₃ - 2·f[1,2])/h₂² = (0 - 3/2 + 2)/1 = 1/2 s(x) = 1 + 0·(x-1) - (3/2)(x-1)² + (1/2)(x-1)³ pe [1,2] Verificare: s(1)=1 ✓, s(2)=1-3/2+1/2=0 ✓
Evaluare în t=0.5 (Horner) Intervalul k=1 (t=0.5 ∈ [0,1]): s = 0.5 - 0 = 0.5 z = 0 + 0.5*(3/2 + 0.5*(0 + 0.5*(-1/2))) = 0 + 0.5*(1.5 + 0.5*(-0.25)) = 0 + 0.5*(1.5 - 0.125) = 0 + 0.5*1.375 = 0.6875

Problema 2 — Spline Cubic Parametric

Cerință

Desenați o curbă spline cubică parametrică printr-o mulțime de puncte

Funcție: my_spline_param(pts, type) — returnează (xx, yy) pe grilă fină.

Algoritm
  1. Parametru t = [0, 1, 2, ..., N-1]
  2. cx = my_cubic_spline(t, pts(:,1), 2) → coeficienți pentru x(t)
  3. cy = my_cubic_spline(t, pts(:,2), 2) → coeficienți pentru y(t)
  4. tt = linspace(0, N-1, 500) → grilă fină de evaluare
  5. xx = my_eval_spline(t, cx, tt), yy = my_eval_spline(t, cy, tt)
  6. plot(xx, yy) → curba netedă
De ce funcționează parametrizarea cu index?

Fiecare nod k are parametrul t=k. Spline-ul pe t garantează că curba trece exact prin punctele (x(k), y(k)) și este netedă (C² în parametru t). Alternativă mai bună: parametrizare prin lungime de arc, dar mai complexă.

Conexiunea cu fonturile reale

Fonturile PostScript și TrueType folosesc curbe Bézier cubice (înrudite cu spline Hermite) pentru a stoca literele cu câțiva parametri. Un font complet poate fi stocat în câțiva KB, redabil la orice rezoluție. De aceea fonturile vectoriale arată bine la orice dimensiune.
