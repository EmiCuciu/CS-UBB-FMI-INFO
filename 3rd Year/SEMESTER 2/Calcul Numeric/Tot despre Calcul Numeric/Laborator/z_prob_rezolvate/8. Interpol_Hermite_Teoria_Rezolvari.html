Teorie

Metoda lui Powell — Idee

Problema de interpolare Hermite

Date: noduri x_k, valori f(x_k) și f'(x_k)

Se caută H_{2m+1}f ∈ P_{2m+1} unic cu:

H_{2m+1}f(x_k) = f(x_k) și H'_{2m+1}f(x_k) = f'(x_k), k=0,...,m

Total 2(m+1) = 2m+2 condiții → grad ≤ 2m+1. ✓

Cheia metodei Powell

Dublarea nodurilor → redus la o DD standard

  1. Definim secvența de noduri duble: z₀=z₁=x₀, z₂=z₃=x₁, ..., z_{2m}=z_{2m+1}=x_m
  2. Diferența dividată cu nod dublu (limită): f[z_{2k}, z_{2k+1}] = f[x_k, x_k] = f'(x_k)
  3. Restul tabelei se calculează exact ca la DD standard
  4. Se aplică polinomul Newton cu nodurile z și coeficienții din prima linie a tabelei

Algoritmul — Tabela DD cu Noduri Duble

Structura tabelei (m=2: 3 noduri → 6 rânduri)

z = [x₀, x₀, x₁, x₁, x₂, x₂]

z_iD⁰D¹D²D³D⁴D⁵
z₀=x₀f(x₀)f'(x₀) ★…………
z₁=x₀f(x₀)f[x₀,x₁]………
z₂=x₁f(x₁)f'(x₁) ★……
z₃=x₁f(x₁)f[x₁,x₂]…
z₄=x₂f(x₂)f'(x₂) ★
z₅=x₂f(x₂)

★ = introdus direct din f'(x_k). Albastru = prima linie = coeficienți Newton ai lui H₅f.

Algoritmul pas cu pas
P1. Construieste z: z[2k]=z[2k+1]=x[k], k=0,...,m P2. Initializeaza D^0: Q[2k,0]=Q[2k+1,0]=f[k] P3. Initializeaza D^1 cu derivata (nodul dublu): Q[2k,1] = f'[k] ← POWELL Q[2k+1,1] = (f[k+1]-f[k])/(x[k+1]-x[k]) ← DD standard P4. Pentru j=2,3,...,2m+1: Pentru i=0,...,2m+1-j: Q[i,j] = (Q[i+1,j-1] - Q[i,j-1]) / (z[i+j] - z[i]) P5. Extrage Q[0,0], Q[0,1], ..., Q[0,2m+1] ← coeficienti Newton

Evaluarea cu Formula Newton

Forma Newton a lui H_{2m+1}f

Coeficienții = prima linie a tabelei DD

H_{2m+1}f(t) = Q₀ + Q₁(t-z₀) + Q₂(t-z₀)(t-z₁) + … + Q_{2m+1}(t-z₀)···(t-z_{2m})

Unde Q_k = td(1, k+1) = f[z₀,...,z_k] și z=[x₀,x₀,x₁,x₁,...,x_m,x_m].

Eroarea de interpolare

R_{2m+1}f(x)

R_{2m+1}f(x) = u(x)/(2m+2)! · f^{(2m+2)}(ξ) u(x) = ∏_{k=0}^m (x-x_k)² ← radacini duble la fiecare nod! |R_{2m+1}f(x)| ≤ M_{2m+2}/(2m+2)! · |u(x)| M_{2m+2} = max |f^{(2m+2)}| pe interval

u(x) are rădăcini de ordinul 2 → eroare mai mică near noduri vs Lagrange.

Cubica Parametrică Hermite (Problema 3)

Definiție

Curba care trece prin P₀, P₁ cu tangentele T₀, T₁

Parametrizare cu t ∈ [0,1]. Funcțiile de bază Hermite (grad 3):

h₀₀(t) = 2t³ − 3t² + 1 (blend P₀: h₀₀(0)=1, h₀₀(1)=0) h₁₀(t) = t³ − 2t² + t (blend T₀: h₁₀'(0)=1, rest=0) h₀₁(t) = −2t³ + 3t² (blend P₁: h₀₁(1)=1, h₀₁(0)=0) h₁₁(t) = t³ − t² (blend T₁: h₁₁'(1)=1, rest=0)

Curba parametrică:

P(t) = h₀₀(t)·P₀ + h₁₀(t)·T₀ + h₀₁(t)·P₁ + h₁₁(t)·T₁
Verificarea condițiilor

De ce funcționează bazele Hermite

FuncțieValoare la t=0Derivată la t=0Valoare la t=1Derivată la t=1
h₀₀1000
h₁₀0100
h₀₁0010
h₁₁0001

Proprietatea Kronecker: fiecare bază e 1 la condiția sa și 0 la celelalte → P(0)=P₀, P'(0)=T₀, P(1)=P₁, P'(1)=T₁. ✓

Problema 2 — Grafic f și H_{2m+1}f

Cerință

Reprezentați pe același grafic f și interpolantul Hermite

Strategie
  1. Alege f și nodurile x cu valorile f(x_k) și f'(x_k)
  2. Evaluează H_{2m+1}f pe grilă fină cu my_hermite_eval(x, f, fd, xx)
  3. Plot f cu linie neagră continuă, Hf cu linie roșie întreruptă
  4. Marchează nodurile cu scatter
Comparație Lagrange vs Hermite (aceeași funcție, același m) f(x)=sin(x), noduri x₀=0.30, x₁=0.32, x₂=0.35, evaluare la t=0.34: Lagrange L₂f(0.34) (fara derivate, m=2): eroare ≈ ~10⁻⁴ Hermite H₅f(0.34) (cu derivate, m=2, 6 condiții): eroare ≈ ~10⁻⁹ ← mult mai precis cu aceleași noduri!

Hermite exploatează informația de derivată → convergență mai rapidă.

Problema 3 — Cubica Parametrică Hermite

Cerință

Curbă prin P₀, P₁ cu tangentele T₀, T₁

Rezolvare pe foaie — exemplu numeric

Date de intrare P₀ = (0, 0), T₀ = (1, 3) P₁ = (2, 2), T₁ = (1, −1) t ∈ [0, 1]
Calcul bazelor la t=0.5
  1. h₀₀(0.5) = 2(0.125)−3(0.25)+1 = 0.25−0.75+1 = 0.5
  2. h₁₀(0.5) = 0.125−2(0.25)+0.5 = 0.125−0.5+0.5 = 0.125
  3. h₀₁(0.5) = −2(0.125)+3(0.25) = −0.25+0.75 = 0.5
  4. h₁₁(0.5) = 0.125−0.25 = −0.125
Verificare: h₀₀+h₁₀+h₀₁+h₁₁ = 0.5+0.125+0.5+(−0.125) = 1.0 ✓ x(0.5) = h₀₀·P₀ₓ + h₁₀·T₀ₓ + h₀₁·P₁ₓ + h₁₁·T₁ₓ = 0.5·0 + 0.125·1 + 0.5·2 + (−0.125)·1 = 0 + 0.125 + 1 − 0.125 = 1.0 y(0.5) = 0.5·0 + 0.125·3 + 0.5·2 + (−0.125)·(−1) = 0 + 0.375 + 1 + 0.125 = 1.5 → P(0.5) = (1.0, 1.5) = mijlocul curbei
Verificarea condițiilor marginale t=0: P(0) = h₀₀(0)·P₀ + h₁₀(0)·T₀ + h₀₁(0)·P₁ + h₁₁(0)·T₁ = 1·P₀ + 0·T₀ + 0·P₁ + 0·T₁ = P₀ = (0,0) ✓ t=1: P(1) = 0·P₀ + 0·T₀ + 1·P₁ + 0·T₁ = P₁ = (2,2) ✓ P'(t) = h'₀₀(t)·P₀ + h'₁₀(t)·T₀ + h'₀₁(t)·P₁ + h'₁₁(t)·T₁ h'₁₀(0) = 1 → P'(0) = T₀ = (1,3) ✓ h'₁₁(1) = 1 → P'(1) = T₁ = (1,−1) ✓

Practica 3 — Automobil: poziție și viteză la t=10

Date observație

Strategie
  1. Nodul z = [0,0,3,3,5,5,8,8,13,13] (5 noduri duble → H₉f, grad 9)
  2. f(z_{2k}) = f(z_{2k+1}) = distanța[k]
  3. f'(z_{2k}) = viteza[k] (derivata distanței = viteza)
